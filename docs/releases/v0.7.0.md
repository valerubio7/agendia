# Agendia v0.7.0

Preparación de una versión estable del proyecto completo. La publicación de la imagen y de la GitHub Release está pendiente; estas notas no anuncian un despliegue en producción.

## Cambios destacados

- **WhatsApp:** programación y agrupación de respuestas para respetar el ritmo de conversación (#63); conservación del historial de mensajes manuales del negocio y cancelación de respuestas aún no reclamadas (#69).
- **Asistente e IA:** entrada agrupada completa e historial reciente para generar respuestas (#74), configuración unificada del asistente (#73) e instrucciones globales con texto base fijo visible (#76).
- **Perfil del negocio:** campos simplificados y retirada del almacenamiento anterior, con las migraciones correspondientes (#70, #73).
- **Operación y mantenimiento:** despliegue en un único servidor, una imagen común para los servicios de aplicación y PostgreSQL separado (#60); consolidación de scripts y documentación de CI, CD y base de datos (#58), validación de GitHub Flow (#56) y limpieza de documentación y herramientas obsoletas (#61).
- **Preparación de la publicación:** versiones 0.7.0 coherentes en todo el monorepo. Solo una etiqueta estable cuyo commit tenga CI exitoso en `main` podrá publicar; la imagen conservará su referencia SHA y añadirá el alias de versión con el mismo digest. La GitHub Release se creará únicamente después de verificar la imagen, sin reemplazar versiones existentes.

## Alcance y próximos pasos

La versión incluirá la instantánea completa del commit validado de `main`, no una selección exclusiva de funciones. Al publicar, GitHub añadirá las notas generadas del proyecto para recoger también los cambios integrados hasta ese commit; este archivo se leerá desde ese mismo SHA.

La publicación real y el despliegue siguen pendientes. El despliegue requerirá un flujo independiente y aprobación humana en un entorno de producción protegido; configurar y ejecutar ese entorno no forma parte de esta preparación de publicación.
